Инструкция по компиляции

Настройка проекта и сборка автономного приложения для Windows.

1. Настройка конфигурации .csproj

Добавьте этот блок внутрь основного тега <Project> в файле Codec.csproj, чтобы файл интерфейса автоматически копировался в сборку:

<ItemGroup>
  <None Update="index.html">
    <CopyToOutputDirectory>Always</CopyToOutputDirectory>
  </None>
</ItemGroup>

2. Сборка проекта через терминал

Откройте папку с проектом в командной строке и запустите публикацию:

dotnet publish -c Release -r win-x64 --self-contained true
