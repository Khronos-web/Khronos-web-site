Компиляция в .EXE

Пошаговое руководство по созданию единого автономного дистрибутива.

1. Настройка конфигурации проекта

Добавьте правило автоматического копирования интерфейса в ваш файл проекта:

<ItemGroup>
  <None Update="index.html">
    <CopyToOutputDirectory>Always</CopyToOutputDirectory>
  </None>
</ItemGroup>

2. Команда сборки

Запустите публикацию через терминал в папке проекта:

dotnet publish -c Release -r win-x64 --self-contained true
